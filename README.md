# Shafanna Solutions

**Detroit community navigation, workforce academy, and resource hub.**

Shafanna Solutions is a proposed, Black-founded nonprofit in formation in Detroit, Michigan, organizing thirteen coordinated community services — including Community Intake & Navigation, the Shafanna Academy (CDL/ELDT workforce training pathway in preparation), food security, housing navigation, and re-entry support.

## Live Site

**[coloredinnovator.github.io/shafanna-solutions](https://coloredinnovator.github.io/shafanna-solutions/)**

Deployed automatically via GitHub Pages on every push to `main`.

## Repository Structure

```
index.html              Single-page website
assets/
  hero-detroit.webp     Hero skyline image (990×556, WebP)
  og-detroit.jpg        Open Graph social card (1200×630)
  favicon.svg           Oxblood/gold "S" monogram
  *.webp                Section images with -800w responsive variants
.github/workflows/
  pages.yml             GitHub Pages deployment (publishes index.html, assets/, and .nojekyll)
```
